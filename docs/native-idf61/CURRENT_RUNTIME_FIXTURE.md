# Current Runtime qualification fixture

This qualifier-only successor uses the historical released baseline unchanged.
The original release recipes, source commits and release evidence remain historical
proof; this checkout does not republish or retrospectively qualify those releases.

The host Runtime now receives explicit metadata FileSources for both supplied
roots. Cohort ELF bytes are read through the candidate Runtime imageSource and
RuntimeFileImage before unchanged production ELF role/import admission. Metadata
reads are host fixture reads; hardware and product storage callbacks must remain
zero. Neither Xtensa instructions nor device hardware are exercised.

The X4 qualifier, where applicable, compares exactly one linked Runtime version in
both ELF and BIN against the version in the locked Runtime source, as consumed by
IDF CMake. Candidate product identity, final linked startup mutations, strict SD
admission, immutable baseline payloads, IQ placement and source custody remain
required. Run tests/test_current_native_fixture.py and the existing provenance
and candidate suites, then the fresh same-process native product matrix.
