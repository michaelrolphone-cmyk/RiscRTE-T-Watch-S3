# Watch 1.1.7 scrolling diagnostic

This complete successor retains the delivered 1.1.6 crown/five-second recovery, offline direct sharing, Contexts 0.4.2/service 0.3.2 fixes, all 25 apps, 30 providers and existing authority. It explicitly selects compact Watch source f1d8d5d and PORTABLE_ASYNC_RGB565 for 19 generic apps. Their app versions advance one patch beyond 1.1.6. Files, Contexts scene and the remaining provider/app bytes keep their qualified 1.1.6 source and versions.

The asynchronous renderer decouples input and logical animation from panel completion, replacing pending frames with the latest complete state. It uses one 115200-byte private canvas. Its source passes 172 lifecycle cases, eight real Stopwatch cases, 14 legacy suites and all 19 target builds. Modeled 240ms display latency drops the longest logical poll from 260ms to 20ms; physical timing, heap margin and smoothness have not been measured.

The compact ancestry is intentional; this is not a direct replacement of the modern shared System adapter. Newer X4 keyboard/resident/paper features are not claimed. Exact compiled Runtime3b90 is retained with private-AP, entropy and AXP2101 crown flags. The later shared Runtime PSRAM-target opt-in is not needed by this established Watch profile.

Use scripts/build_watch_crown_recovery.py with the published compact source, the complete verified 1.1.5 baseline, and the other exact recipe inputs. Assemble with the product identity in docs/shared-files/product.json, then run complete-image admission against the actual selected native. Final receipts supersede preflight measurements.

This is a full initial image and erases internal settings, saved Wi-Fi credentials and application data. Hardware testing and a data-preserving upgrade remain unqualified. Shared SD settings remain disabled.
