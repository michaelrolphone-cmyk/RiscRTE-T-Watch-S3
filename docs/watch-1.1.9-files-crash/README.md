# Watch 1.1.9 Files crash test

This complete test increment retains the 1.1.8 Springboard cooperative-raster and monotonic-clock repair, all 25 apps and 30 providers, crown/five-second recovery, offline sharing features, Contexts 0.4.2/service 0.3.2 and existing authority. Native Runtime remains the exact compiled 3b90 image.

Files advances to 1.5.29. Its guarded Runtime API wrapper previously copied only the older SDK prefix while advertising the larger native table. The fix synchronizes the append-only SDK clock/exit suffix and ensures all copied wrappers advertise only their actual copied extent. Existing native callbacks, including crown exit, remain forwarded.

Real Files initialization, first draw, polling, native exit and cleanup passed five native-table variants in normal and ASan/UBSan tests. The original source reproduces the copied-table overread. These checks do not establish hardware qualification. The delivered 1.1.6/1.1.7/1.1.8 Files crash remains a historical defect; this new test image requires physical confirmation.

Only the Files ELF/manifest and product cohort identity are intended to change from 1.1.8. The complete image must pass exact-native admission and byte-preservation checks before delivery.

The Watch has no SD dependency. This is a full initial flash image and erases internal settings, saved Wi-Fi credentials and application data. A data-preserving update is not qualified.
