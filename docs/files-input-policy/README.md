# Files lifecycle-overlay policy recipe

Local preparation for Files 1.5.35. Source selection remains pending until an
exact public System commit is selected. Provisional receipts are explicitly
marked and cannot enter public qualification without the public-source gate.

The component builder replays every selected Watch/X4 Files 1.5.34 define and
adds only `PORTABLE_TEXT_INPUT_POLICY`. Watch retains LTO and accepted ELF
metadata-only compaction. X4 retains its unmodified target format, native-time
SDK, resident client, sharing, scrolling, raster snapshot and all fonts.
The X4 reconstructed predecessor command must reproduce its selected ELF
byte-for-byte. The disabled-policy target check requires exact selected predecessor bytes on
Watch. X4 permits only enumerated local compiler-symbol numeric suffix changes
in non-allocated .strtab; every other section must be byte-identical and
independent loader-metadata-v3 compaction must produce identical bytes. The
production X4 ELF is not compacted by this recipe.

The Watch overlay uses the complete qualified LoRa/Spectrum/Timecard baseline
at recipe 5664da64e83a2a006d73773fadf966ef66b66ad7, with exactly 55 ELFs and
113 files. It retains at least two free SPIFFS blocks. Only Files ELF, Files
version and cohort source identity are substantive changes. When necessary,
an explicit unsigned-manifest allowlist permits deterministic whitespace
packing. Duplicate keys and non-finite numbers are rejected; decoded values
are compared with scalar types preserved. Signed or unknown metadata cannot
be packed. Boot bytes, grants, native firmware, every unrelated ELF, RF 0.3.4,
all feature flags and original fonts remain unchanged. RF 0.3.5 is excluded.
Full-image hashes are streamed; this recipe never writes a full image.

The X4 overlay preparer accepts an explicitly hashed cumulative baseline
receipt and emits only file_browser.elf and file_browser.json. The settings
composer owns final native/internal/SD qualification; this component overlay
alone is not evidence of complete X4 qualification.

Qualification comprises recipe regression tests, exact disabled-policy
predecessor equality, real ELF-loader validation, actual Xtensa entry-frame
inspection and static modal-buffer size checks, plus normal and sanitized
complete-cohort admission. Host admission does not execute target
instructions, establish dynamic call-chain peak stack, or qualify hardware.
Nothing is flashed or delivered by these scripts.
